This module gets your environment ready. The main path uses the computer you already own. The optional lab adds two virtual machines for the exercises that require breaking something on purpose.

## In This Module

- Confirm the built-in networking commands on your operating system
- Install Wireshark and take a first capture
- Understand which exercises need the lab and which do not
- Optionally build the two-VM lab

## Planned Coverage

### Main Path Tools

- Windows first, with Linux and macOS equivalents shown alongside
- Built in already: `ipconfig`, `route print`, `arp`, `netstat`, `nslookup`, `tracert`, `curl`
- Installed: Wireshark, and optionally a modern DNS client for `dig`
- Verification step so the reader confirms each tool runs before moving on

### Optional Lab

:::tip[Optional Lab]
Lab sections appear in a callout like this one throughout the guide. Skipping every one of them still leaves a complete guide.
:::

- Two VMs in VirtualBox on an isolated NAT Network
- WINCLIENT, Windows 11 Enterprise evaluation, 4 GB RAM, 64 GB disk, the familiar GUI side
- LINUXBOX, minimal Debian, 1 GB RAM, 10 GB disk, plays server, router, and proxy in later modules
- Roughly 5 GB of VM memory and 75 GB of disk in total
- Note the 90 day Windows evaluation timer and how to check it
- Every Linux command in this guide is given as copy-paste, so no prior Linux experience is assumed
